# PETTY CASH LEARNING - LMS Media Belajar Akuntansi Kas Kecil

> **Platform Learning Management System (LMS) Digital Interaktif untuk Pembelajaran Akuntansi Materi Kas Kecil (Petty Cash) bagi Guru dan Siswa.**

---

## 🌟 Tentang Platform

**PETTY CASH LEARNING** adalah aplikasi web edukatif modern yang dikembangkan khusus untuk mempermudah proses belajar mengajar materi **Kas Kecil (Petty Cash)** pada program keahlian Akuntansi dan Keuangan Lembaga (AKL) tingkat SMK/SMA maupun pengantar akuntansi perguruan tinggi.

Website ini mengusung desain **modern, ceria, colorful, dan interaktif** dengan paduan warna harmonis **Biru, Ungu, Kuning, dan Putih**, tata letak berbasis kartu (*card-based layout*), sudut membulat lembut, bayangan halus, serta animasi ringan yang menyenangkan bagi pelajar.

---

## 🚀 Cara Menjalankan Website

Aplikasi ini dibangun menggunakan arsitektur **Modern Client-Side Single Page Application (SPA)** murni tanpa memerlukan instalasi Node.js, Python, atau dependensi server yang rumit:

1. Buka folder `e:\LMS MEDIA BELAJAR\`.
2. Klik ganda (double-click) pada file **`index.html`** untuk membukanya langsung di peramban favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, atau Safari).
3. Anda juga dapat menjalankannya melalui web server lokal (seperti Live Server di VS Code).

## 📚 Struktur Kurikulum Kas Kecil (Bab 1 s/d Bab 5)

Seluruh konten akuntansi disusun secara sistematis sesuai Standar Akuntansi Keuangan (SAK) dan kurikulum AKL:

### 📖 BAB 1 – Pengenalan Kas Kecil
- Pengertian dan latar belakang pembentukan Kas Kecil (*Petty Cash*).
- Tujuan pembentukan: kelancaran operasional harian, efisiensi waktu & biaya, pelayanan prima, serta pencegahan fraud.
- Karakteristik kas kecil: plafon anggaran, batas pengeluaran wajar, pengelolaan kasir kas kecil, penyimpanan di *petty cash box*.
- Contoh pengeluaran nyata: pembelian materai, konsumsi rapat internal, ATK darurat, ongkos kurir kilat, perlengkapan kebersihan.

### 📋 BAB 2 – Pengelolaan Kas Kecil
- 4 Pihak yang bertanggung jawab: Bagian Utang/Akuntansi, Bagian Kasa/Bendahara Umum, Kasir Kas Kecil, dan Departemen Pemakai.
- Prosedur Pembentukan Dana Kas Kecil.
- Prosedur Penggunaan & Pembayaran Kas Kecil.
- Prosedur Pengisian Kembali Dana Kas Kecil.
- 6 Bukti dan dokumen transaksi baku: Cek Tunai, BKK (Bukti Kas Keluar), BPKK (Bukti Pengeluaran Kas Kecil), PPKK (Permintaan Pengisian Kembali), Nota Kontan/Struk, dan Kuitansi.

### ⚖️ BAB 3 – Metode Pencatatan Kas Kecil
- **Metode Dana Tetap (*Imprest Fund System*)**: saldo rekening kas kecil di buku besar selalu tetap, saat pengeluaran tidak dibuat jurnal di buku besar, jurnal beban baru dibuat saat pengisian kembali.
- **Metode Dana Berubah-Ubah (*Fluctuating Fund System*)**: setiap pengeluaran langsung didebet ke akun beban dan dikredit ke Kas Kecil, saldo kas kecil berfluktuasi.
- Tabel komparasi mendalam antara sistem Imprest vs Fluktuasi berdampingan.
- Perbandingan kelebihan, kelemahan, dan aspek pengendalian internal (*internal control*).

### ✍️ BAB 4 – Pencatatan Transaksi Kas Kecil
- Kaidah Debet / Kredit akun Kas Kecil (golongan Aset Lancar).
- Aturan jurnal pembentukan, pengeluaran harian, dan pengisian kembali kedua metode.
- Analisis Jurnal Penyesuaian Selisih Kas:
  - **Selisih Kas Kurang (*Cash Shortage*)**: dicatat di Debet sebagai beban lain-lain.
  - **Selisih Kas Lebih (*Cash Overage*)**: dicatat di Kredit sebagai pendapatan lain-lain.
  - Jurnal penyesuaian akhir periode pada sistem imprest jika belum sempat dilakukan pengisian kembali.
- Contoh soal komprehensif PT Maju Jaya Makmur beserta tabel pembahasan penjurnalan per tanggal transaksi.

### 📊 BAB 5 – Evaluasi dan Studi Kasus
- Panduan identifikasi transaksi: kriteria pengeluaran kas kecil vs kas besar bank.
- Studi Kasus Riil Audit: Kasus cash opname PT Sinar Abadi Mandiri bulan Oktober 2024 dengan plafon Rp 5.000.000,- dan temuan selisih kas fisik.
- Rangkuman esensial materi dan glosarium istilah akuntansi.

## 🎮 Fitur-Fitur Interaktif Unggulan

1. **Simulator Jurnal Akuntansi Real-Time:**
   - Siswa dapat memilih skenario transaksi (Pembentukan, Pengeluaran ATK, Pengisian Kembali Imprest, Selisih Kas Kurang).
   - Memilih akun Debet dan Kredit serta memasukkan nominal.
   - Tombol **"Periksa Jawaban Jurnal Saya"** secara cerdas memvalidasi apakah Debet == Kredit dan apakah pilihan akun sesuai dengan metode yang diinstruksikan.
   - Memberikan skor akurasi dan menampilkan kunci jurnal standar beserta analisis konseptualnya.

2. **Kuis Interaktif 5 Tipe Soal:**
   - Menyajikan 1 soal per layar dengan transisi mulus.
   - Tipe soal: Pilihan Ganda, Benar/Salah, Menjodohkan Istilah Akuntansi (*click & match*), Studi Kasus, dan Perhitungan Jurnal.
   - Umpan balik seketika (*instant feedback*) dengan highlight hijau/merah dan pembahasan detail.
   - Papan hasil akhir menampilkan skor (0-100), jumlah benar/salah, animasi confetti perayaan, tombol ulangi kuis, dan tombol simpan ke rapor siswa.

3. **Efek Suara Audio Interaktif (Web Audio API):**
   - Suara sintetis dinamis native peramban: nada klik tombol, melodi jawaban benar (*happy chime*), nada jawaban keliru (*soft thud*), dan arpeggio kemenangan saat lulus kuis.
   - Dilengkapi tombol Mute/Unmute audio di navbar atas dengan preferensi tersimpan di memori.

4. **Penyimpanan Lokal Persisten (*LocalStorage*):**
   - Progres materi, video yang ditonton, nilai kuis, pengumpulan tugas, nilai dari guru, pengumuman, dan riwayat diskusi tersimpan otomatis di *localStorage* browser.
   - Disediakan tombol **"Reset Data Percobaan"** di bagian footer jika ingin mengembalikan simulasi ke kondisi bawaan awal.

## ⚡ Panduan Deploy ke GitHub Pages (Super Cepat)

Jika mengunggah website ini ke **GitHub Pages**, pastikan langkah berikut agar website terbuka **cepat tanpa lemot**:
1. **Sertakan file `.nojekyll`**: Berkas `.nojekyll` sudah dibuat di root proyek. Berkas ini memberi tahu GitHub Pages untuk tidak menjalankan proses compiler Ruby Jekyll yang memakan waktu lama saat deploy.
2. **Semua Aset Bersifat Mandiri / Zero External Image Latency**: Foto profil dan thumbnail video menggunakan SVG Data URI lokal sehingga tidak bergantung pada server gambar eksternal (Unsplash) yang sering lambat di beberapa provider internet Indonesia.
3. **Optimasi Font & Preconnect**: Font dan CDN sudah dioptimalkan dengan `preconnect` dan `font-display: swap` agar teks langsung muncul dalam hitungan milidetik.
4. **Pengaturan GitHub Pages**:
   - Di halaman repository GitHub: Masuk ke tab **Settings** > **Pages**.
   - Pada bagian **Build and deployment** > **Source**, pilih **Deploy from a branch**.
   - Pilih branch `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
   - Tunggu sekitar 1-2 menit hingga URL `https://username.github.io/nama-repo/` aktif.
